# RNN과 LSTM 알고리즘

## 1. 왜 RNN과 LSTM이 필요한가?

일반적인 신경망은 입력을 처리하지만, **입력 순서가 중요한 문제**에서는 과거 정보를 함께 활용해야 한다. 예를 들어 학생의 내일 스트레스를 예측하려면 오늘 수면 시간뿐 아니라 지난 며칠간의 수면·활동 변화도 중요할 수 있다.

- **시계열 데이터**: 시간 순서대로 관측된 값(예: 월~일 수면 시간, 매일 스트레스 점수).
- **RNN(Recurrent Neural Network, 리커런트 뉴럴 네트워크, 순환신경망)**: 이전 단계의 요약 정보를 다음 단계로 전달하는 신경망.
- **LSTM(Long Short-Term Memory, 롱 쇼트텀 메모리, 장단기 기억 네트워크)**: RNN 계열로, 정보를 유지하거나 버리는 과정을 게이트로 조절한다.

**비유:** 일반적인 단일 시점 모델이 '오늘의 일기 한 장'을 읽는다면, RNN은 '일기를 날짜 순서대로 읽으며 메모'한다. LSTM은 여기에 '중요한 메모는 오래 보관하고 덜 중요한 것은 정리하는 장치'를 추가한 것이다.

## 2. RNN의 작동 원리

### 2.1 기억을 다음 시점으로 전달한다

RNN은 현재 입력 $x_t$와 이전 은닉 상태 $h_{t-1}$를 결합해 새로운 은닉 상태 $h_t$를 만든다. 은닉 상태는 과거 입력을 **완벽하게 저장한 원본**이 아니라, 학습된 방식으로 압축한 숫자 벡터이다.

```text
월요일 입력 x1 ──> [RNN] ── h1 ──>
화요일 입력 x2 ──> [RNN] ── h2 ──>
수요일 입력 x3 ──> [RNN] ── h3 ──> 예측
                    ↑ 이전 단계의 정보가 다음 단계로 전달됨
```

대표적인 단순 RNN 계산식은 다음과 같다.

$$
h_t=\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b_h)
$$

| 기호 | 쉬운 의미 |
|---|---|
| $x_t$ | 오늘 새로 들어온 데이터 |
| $h_{t-1}$ | 어제까지 처리한 정보를 요약한 기억 |
| $W_{xh}$ | 오늘 정보에 부여하는 학습된 가중치 |
| $W_{hh}$ | 이전 기억에 부여하는 학습된 가중치 |
| $b_h$ | 편향 |
| $\tanh$ | 계산 결과를 -1에서 1 사이로 변환하는 함수 |
| $h_t$ | 오늘까지의 정보를 반영한 새로운 기억 |

### 2.2 쉬운 예시 ① 학생의 스트레스 예측

| 날짜 | 수면 시간 | 관찰된 상황 |
|---|---:|---|
| 월요일 | 5시간 | 과제 마감 |
| 화요일 | 4시간 | 시험 준비 |
| 수요일 | 6시간 | 운동함 |
| 목요일 | 7시간 | 휴식함 |

목요일만 보면 수면 7시간으로 비교적 양호하다. 그러나 RNN은 앞선 월·화요일의 수면 부족과 수요일의 회복 과정도 요약해 **금요일 스트레스가 높을 확률**을 계산할 수 있다. 실제 영향의 크기와 방향은 데이터로 학습해야 하며, 이 표만으로 스트레스 결과가 결정되는 것은 아니다.

### 2.3 쉬운 예시 ② 문장 이해

문장: **“나는 어제 산 사과를 오늘 먹었다.”**

RNN은 '나는 → 어제 → 산 → 사과를 → 오늘 → 먹었다'를 순서대로 처리한다. 뒤쪽의 '먹었다'를 처리할 때 앞쪽의 '사과' 정보를 활용할 수 있다. 다만 문장이 매우 길어지면 앞부분의 중요한 정보를 학습하기 어려워질 수 있다.

### 2.4 숫자로 보는 한 단계

단순화를 위해 입력과 기억이 각각 숫자 하나라고 가정한다.

- 현재 입력 $x_t=0.8$, 이전 기억 $h_{t-1}=0.5$
- 가중치 $W_{xh}=0.6$, $W_{hh}=0.4$, 편향 $b_h=0$

$$
h_t=\tanh(0.6\times0.8+0.4\times0.5)
=\tanh(0.68)\approx0.592
$$

새로운 기억은 약 **0.592**이며 다음 단계로 전달된다. **주의:** 이 값은 스트레스 확률 59.2%가 아니라 은닉 상태의 예시 값이다. 확률을 얻으려면 별도의 출력층 등이 필요하다.

## 3. RNN은 어떻게 학습하는가?

1. **순전파**: 날짜별 데이터를 차례대로 읽고 예측값을 계산한다.
2. **손실 계산**: 예측과 실제 정답의 차이를 손실함수로 계산한다. 스트레스 높음/낮음 분류에는 이진 크로스 엔트로피를 사용할 수 있다.
3. **시간 역전파(BPTT, Backpropagation Through Time)**: 마지막 예측 오차가 과거 시점의 계산과 가중치에 어떻게 연결되는지 기울기를 구한다.
4. **가중치 갱신**: 경사하강법, RMSprop, Adam 같은 최적화 방법으로 가중치를 수정한다.

**쉬운 예시:** AI가 내일 스트레스가 낮을 확률을 80%로 예측했지만 실제로 높았다면, 오차를 이용해 수면 부족과 활동 변화에 반응하는 가중치를 조정한다. 같은 RNN 셀은 여러 시점에서 **가중치를 공유**한다.

## 4. RNN의 한계: 오래전 정보를 학습하기 어렵다

RNN의 핵심 한계 중 하나는 **장기 의존성(Long-Term Dependency)** 학습의 어려움이다.

- **기울기 소실**: 역전파가 여러 시점을 거치며 기울기가 매우 작아져, 오래전 입력의 영향을 학습하기 어려워진다.
- **기울기 폭발**: 기울기가 지나치게 커져 학습이 불안정해질 수 있다.

**쉬운 예시:** 한 달 전부터 누적된 수면 부족이 오늘 스트레스와 관련되어 있어도, 일반 RNN은 그 오래된 단서를 충분히 학습하지 못할 수 있다. '과거 정보를 반드시 잊는다'는 뜻은 아니며, 학습이 어렵다는 의미다.

## 5. LSTM은 무엇이 다른가?

LSTM은 RNN의 한 종류로, **셀 상태(Cell State)**라는 정보 전달 경로와 **세 가지 게이트(Gate)**를 사용한다. 각 게이트는 보통 0~1 사이의 값을 출력하여 정보가 얼마나 통과할지 조절한다.

| 게이트 | 역할 | 쉬운 비유 |
|---|---|---|
| 망각 게이트(Forget Gate) | 이전 셀 상태에서 얼마나 유지할지 결정 | 오래된 메모 정리 |
| 입력 게이트(Input Gate) | 새 정보를 얼마나 저장할지 결정 | 중요한 메모 추가 |
| 출력 게이트(Output Gate) | 현재 은닉 상태로 무엇을 드러낼지 결정 | 필요한 메모 꺼내기 |

### 쉬운 예시 ③ 시험 기간의 스트레스

학생이 7일 동안 시험을 준비한다고 가정하자.

- **월요일**: 시험이 금요일이라는 사실을 알게 됨 → 예측에 중요한 정보일 수 있으므로 셀 상태에 반영.
- **화요일**: 점심 메뉴가 바뀜 → 스트레스 예측에 별 관련이 없다면 영향이 작게 학습될 수 있음.
- **수요일**: 수면이 3시간으로 줄어듦 → 중요한 새 단서로 반영될 수 있음.
- **목요일**: 시험 준비가 끝나고 충분히 잠 → 최근 변화까지 고려하여 셀 상태 갱신.
- **금요일**: 과거 여러 날의 정보를 바탕으로 스트레스 수준 예측.

이 사례는 게이트의 **가능한 학습 동작을 설명하는 비유**다. LSTM이 시험 일정이나 점심 메뉴의 중요성을 사람이 지정한 규칙대로 판단하는 것은 아니다. 실제로는 학습된 가중치에 따라 게이트 값이 결정된다.

## 6. LSTM 핵심 수식과 해석

대표적인 LSTM의 계산식은 다음과 같다.

**① 망각 게이트**

$$f_t=\sigma(W_f[h_{t-1},x_t]+b_f)$$

이전 기억 $C_{t-1}$을 얼마나 유지할지 정한다.

**② 입력 게이트와 후보 기억**

$$i_t=\sigma(W_i[h_{t-1},x_t]+b_i)$$

$$\tilde C_t=\tanh(W_C[h_{t-1},x_t]+b_C)$$

새로 들어올 정보의 양과 후보 내용을 계산한다.

**③ 셀 상태 갱신**

$$C_t=f_t\odot C_{t-1}+i_t\odot\tilde C_t$$

이전 정보의 유지분과 새로운 정보의 추가분을 합친다. $\odot$는 원소별 곱이다.

**④ 출력 게이트와 은닉 상태**

$$o_t=\sigma(W_o[h_{t-1},x_t]+b_o)$$

$$h_t=o_t\odot\tanh(C_t)$$

갱신된 셀 상태에서 현재 출력에 사용할 정보를 정한다.

**기호 설명:** $\sigma$는 시그모이드 함수, $C_t$는 셀 상태, $h_t$는 은닉 상태, $W$와 $b$는 학습되는 가중치와 편향이다. 대괄호 $[h_{t-1},x_t]$는 두 벡터를 이어 붙인다는 뜻이다.

### 쉬운 예시 ④ 셀 상태를 숫자로 갱신하기

한 요소만 있는 셀 상태를 가정한다.

- 이전 셀 상태 $C_{t-1}=0.8$
- 망각 게이트 $f_t=0.9$ → 이전 정보의 90% 반영
- 입력 게이트 $i_t=0.5$ → 새 후보 정보의 50% 반영
- 새 후보 기억 $\tilde C_t=0.6$

$$C_t=0.9\times0.8+0.5\times0.6=0.72+0.30=1.02$$

**해석:** 이전 기억에서 0.72를 유지하고 새 정보 0.30을 더해 셀 상태가 1.02가 되었다. **셀 상태는 확률이 아니므로 1보다 클 수 있다.** 출력 은닉 상태는 별도로 $\tanh$와 출력 게이트를 거쳐 계산된다.

## 7. RNN과 LSTM 비교

| 항목 | 기본 RNN | LSTM |
|---|---|---|
| 정보 전달 | 은닉 상태 중심 | 셀 상태 + 은닉 상태 |
| 기억 조절 | 단순 갱신 | 망각·입력·출력 게이트 |
| 장기 의존성 | 학습이 어려울 수 있음 | 상대적으로 유리함 |
| 구조 | 비교적 단순 | 비교적 복잡 |
| 계산 비용 | 대체로 적음 | 대체로 큼 |
| 활용 예 | 짧은 순서 데이터 | 긴 문장·생체신호·시계열 |

LSTM이 모든 데이터에서 항상 RNN보다 정확한 것은 아니다. 데이터의 양과 성격, 학습 설정에 따라 결과가 달라진다.

## 8. 실제 논문 사례: 대학생 스트레스 예측

*Improving Students’ Daily Life Stress Forecasting using LSTM Neural Networks*에서는 대학생 **142명**의 일상 데이터를 분석했다.

- 입력: 과거 **1~7일**의 설문, 생리신호, 스마트폰 사용, 이동 정보.
- 예측: **다음 날 저녁** 스트레스가 높을지 낮을지의 이진 분류.
- 데이터: **2,276일**, 중첩된 **8일 구간 1,231개**.
- 모델: **LSTM 계층 1개, 노드 32개, 드롭아웃 0.2**, 시그모이드 출력, **이진 크로스 엔트로피** 손실, **RMSprop** 최적화.
- 결과: 모든 특징을 사용한 과거 7일 LSTM 모델 **정확도 83.6%**.
- 생리학적 특징만 사용: **82.4%**.
- 설문을 제외한 객관적·수동 수집 특징만 사용: **81.4%**.

**중요한 구분:** 이 논문은 LSTM을 SVM 및 로지스틱 회귀와 비교했다. **기본 RNN과 LSTM을 직접 비교한 실험은 아니다.** 또한 이 수치가 모든 학생이나 모든 상황에서 그대로 재현된다는 뜻도 아니다.

## 9. 추가 쉬운 예시 세 가지

### 예시 ⑤ 주식 가격

월~금 가격과 거래량을 순서대로 입력해 다음 거래일의 가격 방향을 예측할 수 있다. 다만 금융시장은 불확실성이 커서 RNN이나 LSTM을 사용한다고 예측이 보장되지는 않는다.

### 예시 ⑥ 운동 중 심박수

운동 시작 후 심박수의 상승·회복 패턴을 순서대로 입력하면 다음 구간의 심박수를 예측하는 모델을 만들 수 있다. 단일 순간의 심박수보다 **변화 추세**가 유용할 수 있다.

### 예시 ⑦ 문장 감정 분류

“처음에는 무서웠지만 마지막에는 안심했다.”라는 문장에서 RNN/LSTM은 단어 순서를 고려해 전체 문장의 감정 분류에 필요한 특징을 학습할 수 있다. 단어 하나만 보는 것과 다르다.
