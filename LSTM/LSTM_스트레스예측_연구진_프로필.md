# LSTM 기반 스트레스 예측 논문 연구진 4명 프로필

**논문:** *Improving Students’ Daily Life Stress Forecasting using LSTM Neural Networks*

이 논문은 MIT 미디어랩을 중심으로 연구한 4명의 공동저자가 작성했습니다. LSTM을 활용하여 대학생의 생체신호와 행동 데이터를 분석하고 다음 날의 스트레스를 예측한 연구입니다.

## 1. 논문 연구진 개요

| 연구자 | 한글 이름 | 논문에 기재된 소속 |
|---|---|---|
| Terumi Umematsu | 테루미 우메마쓰 | MIT 미디어랩, NEC |
| Akane Sano | 아카네 사노 | MIT 미디어랩, 라이스대학교 |
| Sara Taylor | 사라 테일러 | MIT 미디어랩 |
| Rosalind W. Picard | 로절린드 W. 피카드 | MIT 미디어랩 |

로절린드 피카드는 감성 컴퓨팅(Affective Computing) 분야를 개척한 대표적인 연구자입니다.

## 2. 연구자별 상세 프로필

- 소속: NEC 바이오메트릭스 연구소 수석연구원(Principal Researcher).
- 학력: 일본 와세다대학교 응용물리학 분야 학사·석사·박사; 2024년 공학박사.
- 경력: MIT 미디어랩 방문연구원(2017~2019년).

- 주요 성과: 웨어러블 센서 기반 스트레스 예측, 얼굴 영상 기반 스트레스·졸음·집중력·인지 기능 추정 연구. 2019년 IEEE BHI 최우수논문상 수상.
- 논문과의 관계: LSTM 기반 학생 스트레스 예측 연구의 제1저자. 구체적 저자별 기여 분담은 논문에 명시되어 있지 않음.

## 4. 대학원 강의에서 강조할 내용

연구진의 공통된 관심은 인간의 감정이나 스트레스처럼 직접 관찰하기 어려운 심리적 상태를 생체신호와 행동 데이터로 추정하고 예측하는 것입니다.

**연구의 개념적 흐름:** 피카드의 감성 컴퓨팅 기반 구축 → 사노·테일러의 생체신호 및 웰빙 예측 연구 → 우메마쓰 등 공동연구진의 LSTM 미래 스트레스 예측 성능 검증.

이 흐름은 연구 주제를 이해하기 위한 개념적 구성이지 실제 저자별 지휘 관계나 세부 기여를 의미하지 않습니다.

**강의 토론 질문:** 감정 인식 → 감정 예측 → 적절한 개입 → 실제 효과 검증의 과정에서, 스트레스 예측의 높은 정확도가 실제 스트레스 감소로 이어지는지 어떻게 확인할 수 있을까요?
